# Fix Your Back — UI terv

Kattintható UI terv (React + TSX + Bootstrap) a Fix Your Back honlap és együttműködési portál fejlesztéséhez. Nincs adatbázis/backend — a cél egy programozó számára hasznosítható, böngészőben kipróbálható prototípus.

## Dokumentáció

- [`Projket specifikáció.md`](./Projket%20specifikáció.md) — eredeti követelmény-specifikáció
- [`Design jegyzet.md`](./Design%20jegyzet.md) — a lezárt design rendszer (színek, tipográfia, komponensek)
- [`Fejlesztési napló.md`](./Fejlesztési%20napló.md) — a fejlesztés menete, döntések időrendben
- [`Design elemek/`](./Design%20elemek) — ikonkészlet és korábbi látványtervek

## Futtatás

```bash
npm install
npm run dev
```

## Tech stack

React, TypeScript (tsx), Bootstrap 5 + egyedi CSS-változók, React Router.
